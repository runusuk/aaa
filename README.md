# どうぶつタッチ♪ リズムゲーム 🐶🐰🐱

3歳児向けの、**PCのカメラで体（手）を動かして遊ぶ**リズムゲームです。
音楽に合わせてポコッと出てくる動物さんを、**手をのばしてタッチ**するとポップして得点！
失敗はありません。タッチするたびに褒められて、どんどん楽しくなります。

## あそびかた

1. ゲームをひらく（下の「起動方法」を参照）
2. 「▶ はじめる」を押す
3. カメラの使用を **「許可」** する
4. 画面に動物さんが出てきたら、**手をのばしてタッチ** ！

- 画面はミラー（鏡）表示なので、自分の動きと同じ向きで動かせます。
- 手の位置に🐾（肉球）の光が出ます。これを動物さんに重ねるとタッチ成功。
- 立って遊んでもOK。座ったままでも、手が映っていれば遊べます。

## 起動方法（おすすめ：GitHub Pages で公開）

下の「**Pages を有効にする手順**」を1回だけ行えば、あとは
👉 **https://runusuk.github.io/aaa/**
を開くだけで、サーバー起動なしで遊べます（カメラもそのまま使えます）。

### Pages を有効にする手順（1回だけ・約1分）

1. リポジトリの **Settings**（設定）を開く 👉 https://github.com/runusuk/aaa/settings/pages
2. **「Build and deployment」→「Source」** を **「Deploy from a branch」** にする
3. **「Branch」** で **`claude/awesome-heisenberg-bh43qi`** を選び、フォルダは **`/ (root)`** のまま **Save**
4. 1〜2分まつと、同じページの上に公開URL（`https://runusuk.github.io/aaa/`）が表示されます
5. そのURLを開いて「▶ はじめる」→ カメラを「許可」で遊べます！

### ローカルで動かす方法（Pagesを使わない場合）

カメラを使うため、ファイルを直接ダブルクリックでは動きません（ブラウザがカメラをブロックします）。
このフォルダで次を実行し、表示されたアドレスを開いてください：

```bash
python3 -m http.server 8000
```

ブラウザで 👉 **http://localhost:8000** を開く（サーバーは実行したままにしておくこと）。

> Python が無い場合は Node.js の `npx serve` でもOKです：
> ```bash
> npx serve .
> ```

### 動作環境・コツ

- **ブラウザ**: Chrome / Edge / Safari の最新版を推奨（カメラとWebGLを使います）。
- **インターネット接続が必要**: 体の認識ライブラリ（MediaPipe）を読み込みます。
- **明るい場所**で、上半身（とくに手）がカメラに映るようにすると認識が安定します。
- カメラから1〜2mほど離れて、手が画面内で大きく動かせる位置がおすすめです。

## しくみ（おとな向けメモ）

- すべて1つの `index.html` だけで動きます（追加インストール不要）。
- 手の追跡: **MediaPipe Pose Landmarker**（CDN読み込み）で人差し指／手首の位置を検出。
- 音とエフェクト: **Web Audio API** と Canvas でその場で生成（音声ファイル不要）。
- 動物・効果音・応援メッセージはコード上部の定数を変えれば簡単にカスタマイズできます。
